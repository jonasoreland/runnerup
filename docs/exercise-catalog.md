# Offline exercise catalog

The phone app bundles its initial exercise reference data in `app/src/main/assets/relven/exercise-library-v1.json`. The catalog is available offline and contains original, bilingual English/Swedish instructions for no-equipment bodyweight exercises. Users can also create and edit personal exercises from the Exercises destination. Custom records are stored privately in `files/relven/custom-exercises.json`; English and Swedish names and instructions are required. Editing increments the record revision and preserves its UUID so references in plans and history remain stable. Bundled records stay read-only.

`schemas/exercise-library-v1.schema.json` defines the versioned bundled format. Each exercise has a stable UUID, an exercise revision, a category, movement-pattern key, muscle-group keys, equipment list, localized name, and localized instruction steps. `libraryRevision` versions the bundled catalog as a whole; changing the meaning or instructions for one exercise requires incrementing that exercise's `revision` while keeping its `exerciseId` stable. A new catalog format requires a new `schemaVersion` and parser support.

The Android parser validates the whole bundled library before exposing any entries. Custom records use a separate bounded schema and are merged only after validation. Create, edit, archive, and restore write through an atomic replacement with recovery of the previous file after interruption. Older custom records without archive metadata remain active. Archiving hides an entry from normal browsing but retains its UUID and definition revision; plan and history references continue to resolve. The phone app exposes local search, category filters, active and archived views, create/edit forms, and detail views. Prescriptions, logging, and strength-plan execution are separate product capabilities. No third-party exercise dataset or external media is used.

## Custom collection files

Users can export only their custom exercises to a UTF-8 JSON collection (`relven.exercise-collection`, schema version 1; see [`exercise-collection-v1.schema.json`](../schemas/exercise-collection-v1.schema.json)) or merge one into the local catalog. Bundled catalog entries are never exported or edited. Each custom record retains its UUID, revision, archive state, bilingual names and instructions, category, movement pattern, muscle groups, and equipment. The format has no media or network references.

Imports are limited to 1 MiB and 200 records, and the merged custom catalog remains limited to 200 records. New IDs are added; exact existing records are ignored; duplicate IDs in the file, IDs colliding with the bundled library, or any changed record with an existing ID reject the complete import before the atomic write. Import never deletes local exercises. The Android document picker reports successful additions, an already-present collection, or a failure that leaves current records unchanged.

The JSON Schema describes field types and bounds. Runtime validation also rejects whitespace-only required text, surrounding whitespace in imported text (so import never silently normalizes a collection), case-insensitive duplicate equipment entries, and duplicate exercise IDs even when their records differ.
