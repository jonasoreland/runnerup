# Roadmap

1. **P0 — migration and baseline:** separate fork, Relven identity, attribution and phone/watch debug builds.
2. **P0 — engine and watch HR:** document execution, persistence, audio/export and wearable paths; review RunnerUp PR #1378; test sensor disconnection.
3. **P1 — design and running flow:** export current Stitch screens, correct three planning/detail screens, build shared Compose foundations, migrate essential running/watch UI without duplicating the engine.
4. **P1 — workout import:** FIT Workout decoding and native workout persistence, followed by import-through-execution and activity export verification.
5. **P2 — plans, gym and maps:** JSON plans/calendar, AI Plan Kit from canonical schemas, local exercise catalog, basic strength details, free route maps and metric coloring.
6. **P3 — advanced work:** per-set gym progression, deeper analysis and optional independent watch recording.

Each milestone requires updated [implementation status](implementation-status.md) with actual build, test and device results.
